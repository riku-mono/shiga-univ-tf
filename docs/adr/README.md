# Architecture Decision Records (ADR)

本ディレクトリでは、滋賀大学陸上競技部 公式Webサイトにおける設計・技術選定・運用方針上の重要な判断を **ADR（Architecture Decision Record）** として記録しています。

後輩や新しい担当者へ引き継ぐ際、「なぜ今の仕組みになっているのか」「どの選択肢と比較して採用したのか」を把握するために参照してください。

## ステータスの定義

* **提案中**: 検討・レビュー中の設計判断
* **承認済み**: 採用し、現在の運用・実装に反映されている判断
* **廃止**: 不要となり取り下げられた判断
* **置換済み**: 新しい ADR によって置き換えられた過去の判断

## 新しい ADR の追加方法

重要な技術変更（ホスティング先の変更、スプレッドシートの取得方式や入稿フロー変更、お問い合わせフォームのバックエンド導入など）を行う際は、`NNNN-short-title.md` の形式で新しいファイルを追加し、上記の一覧表を更新してください。
