## 📊 Googleスプレッドシートをデータベースとして連携する手順

1. 部活のGoogleアカウントでGoogleスプレッドシートを作成します。
2. メニューの **「ファイル」→「共有」→「ウェブに公開」** を開き、対象シートと **「カンマ区切り形式（.csv）」** を選んで公開URLをコピーします。
3. [`data.js`](file:///c:/Users/kos12/Work/滋賀大陸上部_webサイト/data.js) の `googleSheetConfig` にURLを貼り付けるだけで、以降はスプレッドシートを書き換えるだけでホームページの「お知らせ」「部員紹介」「滋賀大記録」が自動更新されます。
